# Media

Zet hier de bestanden neer die de placeholders vervangen:

- `folea-hero.mp4` + `folea-hero.webm` — de merkfilm in de hero. Stil, loopend, 10–14 sec.
- `hero-poster.jpg` — eerste frame, voor het geval de video nog laadt.
- `og.jpg` — 1200×630, voor social sharing.
- Productfoto's — zie de labels in de placeholders; elke `<Photo>` draagt zijn eigen shotlist.

Zodra een foto er is: geef `src` mee aan `<Photo>` en de placeholder verdwijnt vanzelf.
